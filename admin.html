Groups and categories

Skill trees: drop skilldatabase_all.json (or the whole output folder) on JSON — trees are placed under Weapon, Buff, Assist, Other from the scrape. Move any category with the dropdown on its row. Press a group to open or close its categories. Each category has two drop buttons. JSON replaces its items with a JSON file, and Image uploads pictures. Drop files on a button, or press it to choose them. All pictures share one folder, so a picture with the same file name replaces the old one.

Add a group

Add a category

Type a name, pick the group it belongs to, then choose its JSON file and any Image files (both optional, you can also drop them on the buttons). Press Add category to register it in that group.

Backup

Download everything (menu layout and every category's items) as one file, and keep it somewhere safe. Pictures are not included, they stay in Supabase. Restoring puts the categories in the file back and replaces ones with the same name.
Drop the file on a JSON or Image button.
