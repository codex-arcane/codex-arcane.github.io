Groups and categories

Press a group to open or close its categories. Each category has two drop buttons. JSON replaces its items with a JSON file, and Image uploads pictures. Drop files on a button, or press it to choose them. All pictures share one folder, so a picture with the same file name replaces the old one.

Backup

Download everything (menu layout and every category's items) as one file, and keep it somewhere safe. Pictures are not included, they stay in Supabase. Restoring puts the categories in the file back and replaces ones with the same name.
Drop the file on a JSON or Image button.
